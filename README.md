# EM_simulation
This repository contains cases comparing various EM solutions generated by three solvers, MOOSE, NGSolve, and COMSOL.

Case 1 - Electrostatic problem (electric potential and current density are produced in the coil)

Problem: Non-zero electric potential at the ground terminal in COMSOL.
Solution: When exporting electric potential from COMSOL, "Recovery" should be set to "None" in data export.
